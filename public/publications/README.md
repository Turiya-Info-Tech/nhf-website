# Publications Directory

This folder is for storing PDF publications that can be downloaded from the website.

## How to Add Publications

1. Add your PDF file to this directory
2. Update the `PublicationsSection.tsx` component to include the new publication
3. Use the path `/publications/your-file-name.pdf` in the `pdfUrl` field

## Recommended File Naming

Use lowercase with hyphens:
- `early-intervention-guide-2024.pdf`
- `parent-handbook-2023.pdf`
- `research-paper-palat-system.pdf`
